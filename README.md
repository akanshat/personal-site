# akansha.site

My portfolio site
**Live:** [akansha.site](https://www.akansha.site)

## Stack

- **Next.js 16** (App Router, fully static) and **React 19**
- **TypeScript** in strict mode with `noUncheckedIndexedAccess`
- **Tailwind CSS v4**, with design tokens as CSS variables (light and dark themes)
- The diagrams use hand-written SVG and React, with no chart or UI libraries
- **GitHub Actions** CI: lint, typecheck, build

## Run Locally

```bash
yarn install
yarn dev
yarn verify
yarn build
```
